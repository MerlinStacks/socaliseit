# Docker Operations

Use this skill for building, deploying, debugging, or modifying the Docker Compose stack.

## Service Topology

```
┌─────────────────────────────────────────────────────────────┐
│  proxy-net (external)                                       │
│  ┌─────────────────────────┐                                │
│  │  webapp (:6754 → :3000) │──┐                             │
│  └─────────────────────────┘  │                             │
│                               │  socialiseit-internal       │
│  ┌─────────────────────────┐  │  ┌───────────┐ ┌─────────┐ │
│  │  worker                 │──┼──│ postgres  │ │  redis  │ │
│  └─────────────────────────┘  │  │ (:5432)   │ │ (:6379) │ │
│                               │  └───────────┘ └─────────┘ │
│  ┌─────────────────────────┐  │  ┌─────────────────────────┐│
│  │  init (one-shot)        │──┘  │  minio (:9000/:9001)    ││
│  └─────────────────────────┘     └─────────────────────────┘│
└─────────────────────────────────────────────────────────────┘
```

| Service | Image / Build | Purpose |
|---------|--------------|---------|
| `webapp` | Dockerfile → `webapp` target | Next.js app server (port 6754) |
| `worker` | Dockerfile → `worker` target | BullMQ background processors |
| `postgres` | `postgres:16.2-alpine` | Primary database |
| `redis` | `redis:7.2-alpine` | Cache + job queues |
| `minio` | `minio/minio:latest` | S3-compatible media storage |
| `init` | `alpine:3.19` | One-shot secret generator |

## Common Commands

All commands run from the **project root** (where `docker-compose.yml` lives).

### Build & Start
```powershell
# Build everything and start
docker compose up -d --build

# Build only one service
docker compose build webapp

# Start without rebuilding
docker compose up -d
```

### Fast Redeploy (Code-Only Changes)
```powershell
# Rebuild + restart webapp only, skip infra health-check waits
docker compose build webapp && docker compose up -d --no-deps webapp

# Same for worker
docker compose build worker && docker compose up -d --no-deps worker
```

### Logs
```powershell
# Follow all logs
docker compose logs -f

# Follow specific service
docker compose logs -f webapp
docker compose logs -f worker

# Last 100 lines
docker compose logs --tail=100 webapp
```

### Restart Services
```powershell
# Restart a specific service
docker compose restart webapp

# Full restart
docker compose down && docker compose up -d
```

### Shell Access
```powershell
# Open shell in webapp container
docker compose exec webapp sh

# Open shell in postgres
docker compose exec postgres psql -U postgres -d socialiseit
```

### Database
```powershell
# Run migrations inside container
docker compose exec webapp npx prisma migrate deploy

# Generate Prisma client
docker compose exec webapp npx prisma generate

# DB backup
docker compose exec postgres pg_dump -U postgres socialiseit > backup.sql
```

## Environment Variables

Source of truth: `stack.env.example`

| Variable | Default | Where Used |
|----------|---------|-----------|
| `DATABASE_URL` | Auto from pg vars | webapp, worker |
| `REDIS_URL` | `redis://:socialiseit_redis@redis:6379` | webapp, worker |
| `AUTH_SECRET` | Auto-generated by init | webapp |
| `ENCRYPTION_KEY` | Auto-generated by init | webapp, worker |
| `S3_ENDPOINT` | `http://socialiseit-minio:9000` | webapp |
| `APP_URL` | `http://localhost:6754` | worker |

> [!IMPORTANT]
> `AUTH_SECRET` and `ENCRYPTION_KEY` are auto-generated by the `init` container on first boot and stored in the `secrets_data` volume. Do NOT manually set these unless migrating.

## Debugging Checklist

| Issue | Steps |
|-------|-------|
| Container won't start | `docker compose logs <service>` → check startup errors |
| DB connection refused | Is postgres healthy? `docker compose ps` |
| Worker not processing | Check Redis connection + `docker compose logs -f worker` |
| Out of memory | Check Docker Desktop memory limits; webapp limit is 1G |
| Migrations not applied | Run `docker compose exec webapp npx prisma migrate deploy` |
| Network issues | Ensure `proxy-net` exists: `docker network create proxy-net` |
| Secrets missing | Check `docker volume inspect socialiseit-secrets` |
